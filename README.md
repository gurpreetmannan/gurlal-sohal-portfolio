## 🚀 Deployment Instructions

This repository is built with standard static web technologies (HTML5, Tailwind CSS via CDN, and Vanilla JavaScript). It requires zero server build steps and can be deployed instantly:

### Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other**.
3. Root Directory: `./` (leave default).
4. Click **Deploy**.

### Deploy to Netlify
1. Connect your GitHub repository on [Netlify](https://www.netlify.com).
2. Build command: *(leave blank)*.
3. Publish directory: `./` (leave default).
4. Click **Deploy site**.

### Deploy to GitHub Pages
1. Go to repository **Settings** &gt; **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Branch: `main` / Folder: `/ (root)`.
4. Click **Save**.
